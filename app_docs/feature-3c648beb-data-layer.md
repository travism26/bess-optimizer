# M1a Data Layer: ERCOT DA Price Fetch and Cache

**ADW ID:** 3c648beb
**Date:** 2026-07-29
**Specification:** specs/M1a_data_layer.md

## Overview

Implements the data layer for the BESS optimizer: fetching ERCOT day-ahead
hourly settlement point prices via gridstatus, normalizing them to the
canonical parquet schema, caching to disk, and validating hard on every
return path. This closes out the `fetch_da_prices` frozen contract and the
`bess fetch` CLI command, both of which previously raised `NotImplementedError`.

## What Was Built

- `fetch_da_prices(location, start, end, cache_dir)` in `src/bess/data/prices.py`,
  serving from a parquet cache when present and fetching via gridstatus when not.
- Canonicalization of gridstatus's raw DAM SPP columns to the frozen schema
  (`interval_start_utc`, `interval_end_utc`, `iso`, `market`, `location`,
  `location_type`, `price`), converting prevailing Central Time to UTC at the
  ingest boundary.
- Hard validation (`_validate`) run on every return path, cache hit or fresh
  fetch: exact columns and dtypes, strict monotonic increasing timestamps, no
  duplicates, no gaps (a gap raises `ValueError` listing the missing interval
  timestamps).
- A fully wired `bess fetch` Typer command: reads `locations`/`start`/`end`/
  `cache_dir` from `config.toml`, overridable by repeatable `--location` and by
  `--start`/`--end`/`--cache-dir` flags.
- A `pytest.mark.manual` marker plus a `conftest.py` carve-out so exactly one
  test (the live gridstatus fetch) is allowed to touch the network, and it is
  excluded from the default run and CI via `addopts = "-q -m 'not manual'"`.
- Three committed fixtures under `tests/fixtures/`: the frozen one-month
  canonical fixture (`hb_north_2023_07.parquet`, 744 rows) plus two small raw
  (pre-canonicalization) fixtures for the 2023 spring-forward and fall-back
  DST days.
- `tests/test_data.py` covering all 8 acceptance criteria from the spec.

## Technical Implementation

### Files Modified

- `src/bess/data/prices.py`: implements `_fetch_raw`, `_canonicalize`,
  `_validate`, `_cache_path`, and `fetch_da_prices`. Only module in `src/`
  that imports gridstatus (imported lazily inside `_fetch_raw`).
- `src/bess/cli.py`: wires `fetch_da_prices` into the `fetch` Typer command,
  reading defaults from `config.toml` via `tomllib` with CLI flag overrides.
- `tests/conftest.py`: `block_network` fixture now exempts tests marked
  `manual`.
- `pyproject.toml`: registers the `manual` pytest marker and excludes it from
  default `addopts`; `gridstatus` was already pinned to `0.36.0`.
- `tests/test_data.py`: full test suite replacing the prior TODO stubs.
- `tests/fixtures/hb_north_2023_07.parquet`,
  `tests/fixtures/hb_north_2023_03_12_raw.parquet`,
  `tests/fixtures/hb_north_2023_11_05_raw.parquet`: frozen fixtures, generated
  once via a real fetch and never regenerated by CI.

### Key Changes

- **DAM archive over recent-documents endpoint:** `_fetch_raw` calls
  gridstatus's `Ercot.get_dam_spp(year=...)` (the yearly DAM archive) rather
  than `Ercot.get_spp()`, because the latter filters on document *publish*
  date and silently returns an empty frame once ERCOT's document list ages
  the relevant postings out. The yearly archive has neither problem for the
  2023-2024 window this project targets. This is documented as a module-level
  comment in `prices.py` since it is a non-obvious constraint that would
  otherwise look like an arbitrary API choice.
- **Canonicalization order of operations:** raw timestamps are converted to
  UTC first, then sliced to the requested Central-calendar-day window; this
  ordering is what keeps DST day boundaries correct (23 or 25 rows, never a
  hardcoded 24).
- **Validation runs on every return path**, including cache hits, so a
  corrupted or hand-edited cache file fails loudly at read time instead of
  silently propagating bad data downstream.
- **gridstatus import isolation** is enforced by a dedicated test
  (`test_gridstatus_import_confined_to_prices_module`) that walks the AST of
  every file under `src/bess/` and asserts none but `data/prices.py` import
  it, rather than relying on code review alone.
- **Manual/live test carve-out:** `tests/conftest.py`'s `block_network`
  fixture checks `request.node.get_closest_marker("manual")` and skips the
  socket guard only for that one test; `pyproject.toml` excludes `manual`
  from the default `pytest` run and therefore from CI.

## Usage

### Examples

```bash
uv run bess fetch --config config.toml                       # use locations/start/end/cache_dir from config.toml
uv run bess fetch --location HB_NORTH --start 2023-07-01 --end 2023-07-31 --cache-dir data
uv run pytest                                                 # default run, network-blocked, manual test excluded
uv run pytest -m manual tests/test_data.py                    # the one live-fetch test, touches the real network
```

```python
from datetime import date
from pathlib import Path

from bess.data.prices import fetch_da_prices

df = fetch_da_prices("HB_NORTH", date(2023, 7, 1), date(2023, 7, 31), Path("data"))
```

## Configuration

`bess fetch` reads defaults from `config.toml`: `locations` (list of hub
names), `start`/`end` (dates), and an optional `cache_dir` key (falls back to
`data/` if absent, since `cache_dir` is not part of the master spec's frozen
config key list). Any of these can be overridden per invocation with
`--location` (repeatable), `--start`, `--end`, and `--cache-dir`.

## Testing

```bash
uv run pytest              # network-blocked; manual test excluded by default
uv run ruff check .
uv run mypy
```

`tests/test_data.py` covers: canonical schema and dtypes on the frozen
fixture, sort/dedupe behavior on synthetic raw input, gap detection with the
missing-interval timestamp in the raised message, both 2023 DST transition
days from committed raw fixtures, negative-price pass-through, cache-hit
behavior (proven by two successive calls under the network guard), and
gridstatus import confinement. The live-network test is marked
`pytest.mark.manual` and must be run explicitly.
